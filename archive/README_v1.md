# Beal Street Senior Affordable Housing (100 Beal Street, Hingham, MA)
## Comprehensive Project Record, Documents, Media & Architectural Archive

<!-- v1 – Project directory master index -->

This archive contains all official town records, architectural diagrams, engineering surveys, news articles, meeting minutes, dates/times, legal contracts, and video broadcast references for the **Beal Street Senior Affordable Housing** project (also referenced as **100 Beal Street** or **School Tract II**) in Hingham, Massachusetts.
